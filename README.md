# Domain Security Scanner

A Flask-based web application that analyzes domain security.

## Features

- MX Record Analysis
- SPF Analysis
- DMARC Analysis
- DKIM Detection
- DNSSEC Check
- HTTPS Security Check
- Open Port Scanning
- Email Security Score
- PDF Security Report Generation

## Tech Stack

- Python
- Flask
- DNSPython
- HTML/CSS
- xhtml2pdf

## Installation

Clone the repository:

git clone https://github.com/BHARATHKUMARN66/domain-security-scanner.git

Install dependencies:

pip install -r requirements.txt

Run the application:

cd backend
python app.py

Open browser:

http://127.0.0.1:5000
